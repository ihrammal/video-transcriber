# اختيار محرّك التفريغ

يحدّد المحرّك كيفية تحويل الكلام إلى نص.

## المحرّك المحلي
يعمل Whisper على جهازك دون إرسال الصوت إلى خدمة سحابية. يتيح التثبيت المخصص اختيار نموذج Tiny أو Base أو Small، أو الاستغناء عن النموذج المحلي لاستخدام مفاتيح API فقط. يثبّت الخيار السريع نموذج Base. بعد تثبيت النموذج لا يحتاج التفريغ المحلي إلى مفتاح API أو اتصال بالإنترنت. قد تستغرق المقاطع الطويلة وقتًا أطول بحسب قدرة جهازك.

## المحرّكات السحابية
ترسل OpenAI وGroq وGoogle Gemini الصوت إلى خدماتها، وتحتاج إلى اتصال بالإنترنت ومفتاح API من المزوّد. تعتمد السرعة والدقة على الخدمة والمقطع.

## الاختيار التلقائي
يستخدم خيار «تلقائي» المحرّك المحفوظ، وقد يجرب محرّكًا بديلًا إذا تعذّر تشغيله. اختر المحرّك المحلي صراحةً إذا أردت التفريغ على جهازك.

## النماذج
تتيح قائمة النماذج تنزيل Tiny وBase وSmall وMedium وLarge v3 وTurbo. تستهلك النماذج الأكبر ذاكرة أكثر عمومًا؛ قارن نتائجها على تسجيلاتك. اختر النموذج من تبويب «التفريغ والترجمة» في الإعدادات. تعرض «حالة النماذج» من قائمة النماذج، باستخدام Ctrl+0، الملفات الموجودة ومساحة التخزين التي تشغلها.


## التفريغ دون اتصال والترجمة عبر الإنترنت
يفرّغ Whisper التسجيلات على هذا الجهاز بعد تثبيت النموذج المختار، ولا يوفّر ترجمة دون اتصال. ترسل ترجمة Google نص التسجيل عبر الإنترنت ولا تحتاج إلى مفتاح واجهة برمجية، بينما تستخدم خدمات OpenAI وGroq وGemini مفاتيحها. يوضّح خيار محرك المعالجة كلا الاستخدامين.

# Troubleshooting

## The program does not start
A crash log is written next to the program; Help then Open log folder (Control plus Shift plus V) opens the folder. Reinstalling keeps your settings and API keys.

## A model will not download
Models then Model status (Control plus 0) shows what is present. The 1.3.1 installer includes all three local models; transcription works offline. A source-code installation may need a first model download.

## A cloud engine fails
Check the key in Settings then Preferences. When a provider rejects the key, the message names the provider, and Automatic falls back to another engine.

## Rendering stops
Rendering needs space for the copy of the video and the fonts on this machine. Cancel (Control plus Shift plus X) is always available and keeps the subtitles you already have.

## Wrong or missing words
Try another model, fix the line yourself in the editor, or import a corrected .srt file with File then Import .srt.

# Getting started

Accessible Video Transcriber turns the speech in a video into editable captions, translates them, and can burn the result back into a copy of the video. Everything can be driven from the keyboard.

## First run
On the first run a welcome screen greets you and focuses the Continue button. The program remembers that it has been seen; pass --welcome on the command line to see it again.

## The five groups
The main window reads top to bottom in five groups: 1 Choose a video file, 2 Task and languages, 3 Run, 4 Progress, 5 Results. Move between groups with the Tab key and between the controls inside a group with Tab or the arrow keys.

## A typical session
Open a video, pick a task and a language, press the Start button (F5), wait for the progress bar, correct anything in the transcript, then export the subtitles or render the subtitled video. When the work finishes or the program exits, it says so and plays a short sound; both can be switched off in the Accessibility menu.

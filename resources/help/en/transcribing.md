# Transcribing speech

## Before you start
Choose Transcribe in the task list, pick the video language (or Automatic) and an engine, then press Start (F5). Progress is announced at every stage: extracting the audio, transcribing, and the percentage finished.

## While it runs
The Cancel button (Control plus Shift plus X) stops the work. The status bar and the screen reader hear the same message, so nothing depends on watching the progress bar.

## When it finishes
The captions appear in the results editor, one segment per line, and the program announces how many lines were produced and in which language. If a target language was chosen, the translation starts right away.

# Exporting and rendering

## Subtitle files
File then Export .srt (Control plus S), and the Export button in the results group, save the captions. The save dialog offers subtitle files and text files: an .srt file always carries the timing, while a .txt file follows the Show timestamps check box.

## Subtitles and video in one step
File then Export subtitles and video (Control plus E) announces the start, writes the subtitle file first, and then asks whether to burn the same captions into a copy of the video. When a video is loaded, the finished file is announced when it is done.

## Rendering
File then Render (Control plus R) burns the current captions into a copy of the video. The default name adds _subtitled to the video name, and the file lands next to the original.

## Clipboard and folder
Edit then Copy results (Control plus Shift plus C) puts every caption on the clipboard, and File then Open output folder (Control plus Shift plus W) opens the folder of the last export.

# Translating captions

## Choosing a target
Group 2 has a target language list. None keeps the original text, the listed languages translate into that language, and Bilingual keeps both: the translation on the line under the original.

## Running a translation
Choose Translate in the task list and press Start. Existing captions are translated as they are, so you can fix a few words first and translate again after a correction.

## What translation keeps
The timing never changes during a translation; only the text of each segment is replaced. Translation runs through the same cloud engine when the provider offers it, and through an online translator otherwise.

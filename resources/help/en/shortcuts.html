How to use this list

  • Hold the keys together, for example hold Ctrl and press O once, then let go.
  • Every shortcut here has a menu twin: open the menu named in the group heading and choose the item with the arrow keys. The menu prints the shortcut next to the item, so you can always discover it again.
  • Menu letters are underlined on screen. Hold Alt and press the underlined letter to open a menu or press a menu item directly.
  • Tab and Shift with Tab move forward and backward through the controls of the main window in reading order, and the focus rectangle always shows where you are.

File

ShortcutItemWhat it does
Ctrl+OOpen Video… Opens the file dialog to choose a video (or an audio file) to work on. You can also drag a file onto the window instead.
Ctrl+IImport .srt… Reads an existing subtitle file into the transcript editor, so you can edit or translate captions you already have.
Ctrl+SExport .srt… Writes the captions to a subtitle file with full start and end times, ready for players and upload sites.
Ctrl+EExport subtitles and video The complete hand-off: announces the start, writes the captions to a subtitle or plain text file, then offers to burn the same captions into a copy of the video, and announces the result.
Ctrl+RRender Subtitled Video… Burns the caption lines into the picture (white text, black outline) in the background and saves a new MP4 file.
Ctrl+Shift+WOpen Output Folder Opens the folder that holds the last file you exported or rendered.
Ctrl+QExit Asks you to confirm, then closes the program and shows the goodbye message.

Edit

ShortcutItemWhat it does
Ctrl+Shift+NAdd Row Adds an empty caption line at the end of the transcript. The program announces the number of the new row.
Ctrl+Shift+DDelete Selected Row Deletes the selected caption line or lines after telling you how many, or telling you that nothing was selected.
Ctrl+Shift+CCopy Results Copies every caption to the Windows clipboard, with the times when Show timestamps is on, and announces the count.

Settings

ShortcutItemWhat it does
Ctrl+,Speech & Translation Settings… Opens the preferences: default speech engine, recognition model, translation service and the API keys with Show, Test and Get API key buttons.
Ctrl+Shift+1Interface in English Switches the whole interface to English; a check mark shows the current language.
Ctrl+Shift+2الواجهة بالعربية Switches the whole interface to Arabic and flips the layout to right-to-left. Refused while a task is running.

Accessibility

ShortcutItemWhat it does
Ctrl+Shift+AAccessibility Settings… Opens the settings window with every accessibility option as a check box: high contrast, larger focus indicators, simplified layout, announced progress and sounds.
Ctrl+Shift+TShow timestamps Check box. Shows or hides the start and end time of every caption in the editor, in plain text exports and in copied text. Subtitle files always keep their times. Remembered between runs.
Ctrl+Shift+HHigh Contrast Theme Check box. Switches to the black and yellow high contrast theme and back.
Ctrl+Shift+LLarger Focus Indicators Check box. Draws a thick, obvious focus rectangle around the control you are on.
Ctrl+Shift+SSimplified Layout Check box. Hides the advanced rows and keeps only the essential controls on the main window.
Ctrl+Shift+PAnnounce Progress Check box. Speaks every progress update while a task runs.
Ctrl+Shift+MPlay Sounds Check box. Plays a short sound when a task finishes or fails.

Tools

ShortcutItemWhat it does
Ctrl+Shift+EExtract Audio Pulls the audio track out of the selected video into a temporary file, without transcribing yet.
Ctrl+Shift+XCancel Task Asks the running task to stop at its next safe point and reports the outcome in the status line.

Models

ShortcutItemWhat it does
Ctrl+1Download Tiny Model (fastest) Downloads the smallest recognition model for the local engine; quickest, with the least accuracy.
Ctrl+2Download Base Model (bundled) Downloads the size the program uses by default. Already installed models answer immediately.
Ctrl+3Download Small Model (most accurate) Downloads the most accurate of the three local models.
Ctrl+0Model Status Lists which models are installed, which are missing and the folder that stores them.

Help

ShortcutItemWhat it does
F1User Guide Opens the combined user guide in your web browser: this document together with the keyboard shortcut list.
Ctrl+/Keyboard Shortcuts Opens the same combined guide straight at the Keyboard Shortcuts section.
Ctrl+UCheck for Updates… Checks the GitHub Releases page for a newer version and reports the result in a clear message.
Ctrl+Shift+UCheck Automatically at Startup Turns the quiet startup check on or off. When it is on, the program checks at most once a day, a few seconds after the window opens, and only speaks up when a newer version exists.
Ctrl+Shift+RRelease Notes on GitHub Opens the release notes page in your web browser.
Ctrl+Shift+BReport a Problem Opens the issue page in your web browser, where a problem can be described.
Ctrl+Shift+GLicense Agreement Opens the License Agreement section of the combined guide. The program is for noncommercial use only.
Ctrl+Shift+VOpen Log Folder Opens the folder with the log file, for diagnosing problems.
F12About Shows the About page: version, accessibility statement, privacy, libraries, license summary and the author's contact details.

The Help menu also offers Open Guide File and Open Shortcut File without shortcuts of their own; they open this guide and this list as files in your default browser.

Main screen

ShortcutItemWhat it does
F5Start Runs the task selected in the Task list: transcribe the speech into captions, or translate the captions already in the editor. Start is the default button of the window.
Alt+F4Close the program Windows closes the program; you are asked to confirm first and thanked when it exits.

General keyboard tips

  • Press Alt once to focus the menu bar, then use the arrow keys; the underlined letters jump straight to a menu.
  • In list boxes, the arrow keys choose, Home and End jump to the first and last entry, and typing a letter jumps to the next entry starting with it.
  • In the transcript editor, Tab leaves the editor and moves to the next control, so a long caption never traps you inside it.
  • Check boxes and menu items that are on carry a check mark; the screen reader reports the state as well as the name.
  • The status line and the progress bar can hold focus: move onto them whenever you want to hear the current state of the program.
  • If you ever lose track of a shortcut, open this list again from the Help menu, or press Ctrl+/ to open the combined guide at the Keyboard Shortcuts section.

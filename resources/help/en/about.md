# About this program

Accessible Media Transcriber is an accessible desktop program by Iman Rammal for audio and video: it turns speech into transcripts and captions, translates them, lets you edit the result in plain text, and creates captioned videos.

## Version
Version 1.3.1.

## Design
The program provides labelled controls, visible status messages and keyboard shortcuts, and exposes controls to screen readers through Windows accessibility interfaces. See ACCESSIBILITY_REVIEW.md for tested coverage and remaining checks.

## Where things live
Settings are stored in your user profile. API keys are stored in Windows Credential Manager. Help topics are read from the program folder, so the text you are reading now is part of the installation.

# About this program

Accessible Video Transcriber is an accessible desktop program by Iman Rammal for video work: it turns speech into captions, translates them, lets you edit the result in plain text, and burns it back into the video.

## Version
Version 1.2.

## Design
It is built against WCAG 2.1 AA and Windows UI Automation: every control has a name, every message is spoken as well as shown, and the whole program runs from the keyboard.

## Where things live
Settings and API keys are stored in your user profile, and the help topics are read from the program folder, so the text you are reading now is part of the installation.

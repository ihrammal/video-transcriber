1. About this guide

This guide is written for two ways of reading at once:

  • For everyone: ordinary paragraphs, a table of contents above, and headings that make the page easy to scan.
  • For screen readers: the page uses one main heading and many level-two and level-three headings, so NVDA, JAWS and Narrator can jump from heading to heading with their heading keys, and read the whole page in order if you prefer.

Two documents belong together: this guide, and the shortcut list. Use the link Keyboard Shortcuts in the contents above, or the Help menu entry Open Shortcut File inside the program. Inside the program, F1 opens the combined user guide and Ctrl+/ opens the same guide straight at the Keyboard Shortcuts section.

Tip: every shortcut in this guide is also written in words in the shortcut list, and every menu in the program shows the shortcut next to its item, so you never have to remember a key from memory alone.

2. What the program does

Accessible Video Transcriber takes a video or audio file and turns the speech into caption lines you can read, edit, translate, save and burn back into the video. The whole program is keyboard driven and built for screen readers, braille displays and low-vision users.

What it can open

MP4, MOV, AVI, MKV, WMV, WebM, FLV, M4V, MPEG, MPG, 3GP, 3G2, TS, MTS, M2TS, OGV, VOB, ASF and MXF video files, plus any other file your computer can play. You choose a file with the Open Video button, with Ctrl+O, or by dragging the file onto the window.

What it produces

  • An .srt subtitle file — the standard caption format with start and end times, readable by players and upload sites.
  • A .txt transcript — plain lines, with or without timestamps depending on the Show timestamps option.
  • A subtitled video — a copy of your video with the caption lines burned into the picture.
  • Clipboard text — the captions copied so you can paste them into a document or a mail.

The engines it can use

  • Local Whisper (free, offline) — recognition runs on your own computer; no key, no internet, no cost.
  • OpenAI API (needs a key), Groq API (needs a key) and Google Gemini API (needs a key) — cloud recognition when you have an account with one of these providers.
  • Automatic — uses your saved choice and falls back to the free offline engine whenever a key is missing.

3. Getting started

Installing the program

The installer asks who may use the program: choose Install for anyone who uses this computer on a shared machine, or Install only for me on your own. If you prefer not to install anything, unzip the program folder anywhere and start AccessibleVideoTranscriber.exe from inside it; the folder is complete and portable. Your settings, your accessibility options and the update history always live in your own user folder, under %LOCALAPPDATA%\Accessible Video Transcriber, so they follow you whichever way you start. Installing a newer version over an old one keeps them, and the program never changes your videos or your transcripts.

The welcome screen

The first time the program opens it greets you with a welcome screen. Pick your language there, then press Continue; if you do nothing, the program opens by itself after three seconds. When you close the program later it thanks you and asks you to confirm that you really want to exit.

Open your first video

  1. Press Alt+O, or move to the Open Video button with Tab and press Enter, or press Ctrl+O.
  2. Choose the file in the file dialog. The full path appears next to the button and is announced.
  3. Alternatively drag a file from a folder and drop it anywhere on the program window.

Pick a task, the languages and an engine

In group 2. Task and languages you decide what the Start button will do:

  • Task: Transcribe speech into captions or Translate the captions that already exist in the editor.
  • Source language (spoken in the video): Automatic detection, English or Arabic. Automatic lets the recogniser detect the language itself.
  • Target language: No translation (keep the original language), or one of the supported languages, or Bilingual stacked (original above, translation below) for two lines per caption.
  • Engine: Automatic, Local Whisper, OpenAI, Groq or Google Gemini, as explained in section 12.

Press Start and wait

Press F5, or the Start button. The status line in group 4. Progress reports each stage, the progress bar shows the percentage, and the result lands in the transcript editor in group 5. Results. Progress messages are spoken when Announce Progress is on. You can keep using the rest of the window while a task runs; only choices that would break the running task are blocked.

4. The five groups of the main screen

The window reads top to bottom as five numbered groups. Each group has a name, a description for the screen reader, and controls that Tab moves through in visual order.

1. Choose a video file

The Open Video button, the label that shows the selected path (the text is selectable with the mouse), and the hint that you can also drop a file onto the window.

2. Task and languages

A small form with four rows: Task, Source language (spoken in the video), Target language and Engine. Every row has a label on the left and a list box on the right. Open a list box with Alt plus its underlined letter, or with the arrow keys once it has focus.

3. Run

Start (F5) runs the chosen task, and Cancel asks the running task to stop. Start is the default button, so pressing Enter almost anywhere in the window runs it too. Cancel stays greyed out while nothing runs.

4. Progress

The status line (for example Status: Ready. Press the Open Video button and use Alt+O to open a video file.) and a progress bar. Both take focus on purpose: park on the status line or the bar and the screen reader reads the current message or percentage back to you at any time.

5. Results

The transcript editor (section 5) and the button row under it: Save results (Ctrl+S), Copy results (Ctrl+Shift+C), Export (Ctrl+E) and the Show timestamps check box (Ctrl+Shift+T).

5. Working in the transcript editor

The results area is an ordinary Windows multiline text box called Transcript editor. Because it is a standard control, every editing key you already know works: arrows, Home, End, Page Up, Page Down, Ctrl with arrows for word movement, selection with Shift, cut, copy, paste, undo and redo.

One caption per line

Each line of the editor is one caption. With timestamps on (section 6) a line looks like this:

[00:00:05,240 --> 00:00:08,120] Hello and welcome to the video.

With timestamps off, the same caption is only its text: Hello and welcome to the video. If a single caption contains a line break, the break is shown as / so that one caption stays on one line.

Adding and deleting lines

  • Ctrl+Shift+N or the Edit menu item Add Row adds an empty caption line at the end.
  • Ctrl+Shift+D or Delete Selected Row removes the lines you selected; the program tells you how many lines it removed, or that nothing was selected.
  • If the number of captions changes while you are editing, the program asks for confirmation before it replaces what is on screen, so a mistyped shortcut cannot destroy your work.

The caret stays yours

The program never moves your caret and never takes focus away from the editor while a task runs. When new captions arrive they are inserted, the scroll position and caret are kept where you put them, and the caption count in the editor's description is updated. If a timestamp line cannot be read, the program reports the exact line number instead of silently dropping it.

6. Timestamps on and off

The Show timestamps check box in group 5. Results (Ctrl+Shift+T) is a viewing option. It is remembered between runs, so the program comes back the way you left it.

WhereEffect of the option
The transcript editorLines show or hide [start --> end] in front of each caption. Turning it on or off reformats the text in place; your wording is kept, the caret does not jump, and the caption count does not change.
Plain text export (.txt) and Copy resultsThe times are included only while the option is on.
Subtitle export (.srt)Always full timing. A subtitle file would be useless without its times, so the option never removes them there.

The time format everywhere is HH:MM:SS,mmm, for example 00:01:23,450. When you type times yourself, use that shape; the program reports the row number if a time is invalid or if an end time is not later than its start time.

7. Saving, copying and exporting

Save results — Ctrl+S

Writes the captions to an .srt subtitle file with full timing. Choose the place and the name in the save dialog. The number of captions written is announced when it is done.

Copy results — Ctrl+Shift+C

Puts every caption on the Windows clipboard, with the times when Show timestamps is on and without them when it is off, and announces how many captions were copied. Paste anywhere: mail, word processor, notes.

Export subtitles and video — Ctrl+E

The one button that does the whole hand-off:

  1. The program announces that the export has started.
  2. A save dialog offers subtitle files (.srt) and plain text files (.txt); pick the format by the file extension you type.
  3. It then offers to burn the same captions into a copy of the video. Accept and a background render begins; decline and you stop at the caption file.
  4. When everything finishes the result is announced: the path of the written file, or the message that there was nothing to export.

Render Subtitled Video — Ctrl+R

Burns the captions straight into the picture with a white font and a black outline, keeps the original audio, and writes a new MP4. Rendering runs in the background; the status line shows the stage (Burning caption lines onto video) and you can cancel it (section 9).

Open Output Folder — Ctrl+Shift+W

Opens the folder that holds the last exported or rendered file, so you do not have to remember where you saved it.

8. Translating the captions

Translation works on captions that already exist — either ones you just transcribed or ones you imported with Import .srt (Ctrl+I).

  1. Set Task to Translate the captions.
  2. Set the Target language to the language you want, or to Bilingual stacked (original above, translation below) to keep both lines together in one caption.
  3. Press F5. The translation runs in the background, the status line reports Translating subtitles in the background, and when it finishes the caption count is announced.

If the target language is No translation the program says so and does nothing, with a message that there was nothing to translate. Translation uses an online service, so a connection is needed; recognition with the local engine is not.

9. Progress, status and cancelling

  • The status line speaks each stage: extracting audio, loading the model, transcribing, translating, rendering, and the matching "finished" message with the result (how many captions, which language was detected, where the file was written).
  • The progress bar runs from 0 to 100 and can hold focus, so you can hear the percentage whenever you want.
  • Cancel (the button or Ctrl+Shift+X) asks the task to stop. The message says the task will stop at the next safe point, and you get either No task was started or Rendering cancelled as the outcome.
  • While a task runs, a few choices are blocked with an explanation — for example the interface language cannot change mid-run — so the program never breaks silently.
  • If a task fails, the status line and the message say what went wrong (extraction, transcription, translation or rendering) instead of hiding the error.

10. Accessibility features

Everything below lives in the Accessibility menu, and most of it is also in Accessibility Settings (Ctrl+Shift+A). Every option has a check mark when it is on, and the settings are remembered.

Contrast and focus

  • High Contrast Theme (Ctrl+Shift+H) switches to a black and yellow WCAG-AAA palette; the check box High contrast mode (black and yellow, WCAG AAA) in the window does the same.
  • Larger Focus Indicators (Ctrl+Shift+L) draws a thick, clearly visible focus rectangle around whichever control has focus, including buttons, list boxes, check boxes and the editor.

Layout and announcements

  • Simplified Layout (Ctrl+Shift+S) hides the advanced rows (source language and engine) and keeps the window to the essentials.
  • Announce Progress (Ctrl+Shift+P) speaks every progress update while a task runs.
  • Play Sounds (Ctrl+Shift+M) plays a short sound on completion and on errors, for users who work without speech.

Notes for screen reader users

  • Every control has a name and a description; the group descriptions explain what the block is for before you enter it.
  • Focus is never moved away from what you are doing: background tasks report through the status line and announcements, not by stealing the caret.
  • The transcript editor is a standard text control, so braille displays follow the caret line by line.
  • Dialogs (preferences, messages) are modal and always announce their title.

11. The interface language, English and Arabic

The whole interface — menus, buttons, messages, help topics and screen reader descriptions — exists in English and Arabic.

  • Ctrl+Shift+1 switches to English, Ctrl+Shift+2 switches to Arabic. The same two items sit in the Settings menu with check marks.
  • In Arabic the layout flips to right-to-left: menus, forms and text start at the right edge, and the arrow keys follow the layout.
  • The choice is remembered, and it is refused while a task is running so that a mid-run change cannot mix up a message.
  • Arabic captions, file names and text in the editor are unaffected by the interface direction — text keeps its own language.

12. Engines, models and API keys

Choosing the engine

The Engine row of group 2 offers: Automatic (my saved choice, with automatic fallback), Local Whisper (free, offline), OpenAI API (needs a key), Groq API (needs a key) and Google Gemini API (needs a key). Picking a specific engine saves it as your preference and announces the choice. With Automatic, a missing key falls back to the free offline engine and the status line says that this happened.

Recognition models for the local engine

  • Download Tiny Model (fastest) — Ctrl+1.
  • Download Base Model (bundled) — Ctrl+2 — the size the program uses by default.
  • Download Small Model (most accurate) — Ctrl+3.
  • Model Status — Ctrl+0 — lists what is installed, what is missing and the folder that holds the models. A model you do not have is downloaded on first use, with spoken progress, and the "already installed" answer is immediate.

API keys

Speech and Translation Settings (Ctrl+,) holds the engine choice, the model choice, the translation service and one key per provider with three buttons: Show key, Test key and Get API key (opens the provider's page where a key is created). Keys are stored in the Windows Credential Manager on this computer only, are only sent to the provider you chose, and never appear in the log file. If you save an engine whose key is missing, the program warns you and offers the local engine instead.

13. Troubleshooting

SituationWhat to do
Something went wrong and you want the detail. Help → Open Log Folder (Ctrl+Shift+V) opens the folder with the newest log file; attach it when you contact the author. The log never contains an API key.
Busy: a background task is already running. Wait for the task to finish, or press Cancel first.
There are no subtitles yet. Transcribe first, or import an .srt file, before translating or exporting.
A row has an invalid timestamp. The message gives the row number and the expected shape HH:MM:SS,mmm; correct that line in the editor.
The model download failed. The message names the model and the reason; check the connection and start the download again from the Models menu.
A key is refused by the provider. Open Speech and Translation Settings (Ctrl+,), paste the key again and press Test key, or switch the engine to Local Whisper and work offline.
Nothing happens when you press a button. Read the status line in group 4 — it always says what the program is waiting for, for example which file to choose first.

Checking for updates

Choose Check for Updates…, or press Ctrl+U. The program asks the GitHub Releases page for the newest version and answers in one clear message: either that you already have the latest version, naming your version, or that a newer version exists, with a Download button that opens the release page in your browser. Nothing is downloaded or installed until you press that button, and the check runs in the background, so the window never freezes.

The automatic check at startup

The item Check Automatically at Startup, or Ctrl+Shift+U, switches the quiet startup check on or off, and a tick mark shows its state. When it is on, the program checks at most once a day, a few seconds after the window opens, and only speaks when a newer version exists; it stays silent when you are up to date. Switch it off if you would rather the program never contacts the network on its own.

General keyboard tips

  • Press Alt once to focus the menu bar, then use the arrow keys; the underlined letters jump straight to a menu.
  • In list boxes, the arrow keys choose, Home and End jump to the first and last entry, and typing a letter jumps to the next entry starting with it.
  • In the transcript editor, Tab leaves the editor and moves to the next control, so a long caption never traps you inside it.
  • Check boxes and menu items that are on carry a check mark; the screen reader reports the state as well as the name.
  • The status line and the progress bar can hold focus: move onto them whenever you want to hear the current state of the program.
  • If you ever lose track of a shortcut, open this list again from the Help menu, or press Ctrl+/ to open the combined guide at the Keyboard Shortcuts section.
